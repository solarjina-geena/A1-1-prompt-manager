# 나만의 프롬프트 관리 프로그램

콘솔 환경에서 다양한 AI 프롬프트를 저장하고 관리할 수 있는 Python 프로그램입니다.  
프롬프트를 추가하고, 목록을 확인하고, 카테고리별 조회·검색·상세 보기·즐겨찾기 관리까지 할 수 있습니다.

---

## 프로젝트 소개

이 프로그램은 자주 사용하는 프롬프트를 효율적으로 관리하기 위해 만든 **콘솔 기반 프롬프트 관리 프로그램**입니다.  
Python의 기본 문법인 **리스트, 딕셔너리, 함수, 조건문, 반복문**을 활용하여 구현했습니다.

사용자는 프롬프트를 직접 추가할 수 있고, 카테고리별로 정리하거나 검색할 수 있으며, 자주 쓰는 프롬프트는 즐겨찾기로 따로 관리할 수 있습니다.

---

## 주요 기능

### 프롬프트 추가
- 제목, 내용, 카테고리를 입력하여 새 프롬프트를 저장할 수 있습니다.
- 카테고리는 **목록에서 선택**하거나 **직접 입력**할 수 있습니다.

### 프롬프트 목록 보기
- 저장된 전체 프롬프트를 한 번에 확인할 수 있습니다.
- 즐겨찾기된 프롬프트는 **⭐ 표시**로 구분됩니다.

### 카테고리별 조회
- 특정 카테고리에 속한 프롬프트만 모아서 볼 수 있습니다.
- 직접 입력한 새로운 카테고리도 조회할 수 있습니다.

### 프롬프트 검색
- 제목 또는 내용에 포함된 키워드로 프롬프트를 검색할 수 있습니다.

### 프롬프트 상세 보기
- 선택한 프롬프트의 제목, 내용, 카테고리, 즐겨찾기 여부를 자세히 확인할 수 있습니다.

### 즐겨찾기 추가 / 해제
- 원하는 프롬프트를 즐겨찾기로 등록하거나 해제할 수 있습니다.

### 즐겨찾기 목록 보기
- 즐겨찾기한 프롬프트만 따로 모아서 확인할 수 있습니다.

## 실행 방법

1. 프로젝트 파일을 다운로드하거나 클론합니다.
2. 터미널에서 프로젝트 폴더로 이동합니다.
3. 아래 명령어로 프로그램을 실행합니다.

```bash
python main.py
```

> 실행 파일명이 다르다면 `main.py` 대신 실제 파일명으로 실행하면 됩니다.
